# Marketing Skills

Vendored from [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) (MIT licensed, © Corey Haines), as a frozen one-time copy on 2026-09-08. These are not kept in sync with upstream — check the source repo directly for updates.

- **product-marketing** — creates/maintains `.claude/product-marketing.md`, the shared context doc (audience, positioning, messaging, voice) every other marketing skill reads first.
- **copywriting** — writes/rewrites page copy (homepage, landing, pricing, feature, about).
- **site-architecture** — plans page hierarchy, navigation, and URL structure.
- **customer-research** — synthesizes ICP/persona research from interviews, reviews, and community sources.

Run `product-marketing` first on a new task to establish or refresh the context doc; the others read it automatically.
